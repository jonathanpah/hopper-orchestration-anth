# hopper-orchestration-anth

[English](hopper-orchestration-anth-en/README.md) | [Português (Brasil)](hopper-orchestration-anth-pt-br/README.md)

A Claude Code skill for coordinating Claude subagents (executor, reviewer, and validator) with verifiable deliverables and recorded evidence, on macOS and Linux.

Uma skill do Claude Code para coordenar subagentes Claude (executor, revisor e validador) com entregas verificáveis e evidências registradas, em macOS e Linux.

Each release includes both languages. The language folders separate documentation and packages; the installed name remains `hopper-orchestration-anth`.
